# 🚗 Used Car Price Prediction

## 📌 Problem Statement
This project focuses on performing **Exploratory Data Analysis (EDA)** to uncover the factors influencing car prices. A **Linear Regression** model is then built using the training dataset to predict prices of used cars in a separate test dataset.

---

## 🧩 Task Breakdown

### 1. 🧼 Data Preprocessing

**Importing and cleaning data:**  
The dataset was imported and carefully cleaned by removing inaccuracies and inconsistencies.

**Feature Engineering:**
- Renamed columns for clarity
- Extracted relevant features
- Encoded categorical variables
- Handled missing values to ensure a robust dataset

---

### 2. 🛠 Model Building

**Train-Test Split:**  
The data was split into training and testing sets for evaluation.

**Modeling:**  
Built a **Linear Regression** model to predict used car prices.

---

## 📊 Conclusion

**Performance:**
- **R² Score:** 0.73
- **Mean Squared Error (MSE):** 37.3

**Key Influencing Factors:**
- Car Name
- Location
- Year
- Kilometres Driven
- Transmission
- Engine
- Seats

These features showed significant impact in determining used car prices based on regression analysis.
